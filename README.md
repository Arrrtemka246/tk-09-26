# Team Kulik — live results

Небольшой статический сайт для 27 спортсменов Team Kulik и 65 стартов на соревнованиях 27–30 сентября 2026.

## Что показывает

- стартовый день, дистанцию, заплыв и дорожку;
- заявочное и фактическое время;
- улучшение/ухудшение относительно заявки;
- место и AQUA / World Aquatics points;
- DSQ, DNS и DNF только если статус явно указан в официальном итоговом протоколе;
- личную карточку каждого спортсмена.

## Автообновление

GitHub Actions раз в 10 минут проверяет `https://funtiak.serv00.net/YM/`, скачивает опубликованные PDF, извлекает данные только по нужным спортсменам и обновляет `data/results.json`.

Принцип безопасности: отсутствие результата **никогда** не считается дисквалификацией. DSQ/DNS/DNF записывается только при явной отметке в официальном результате.

## Публикация бесплатно

Репозиторий рассчитан на GitHub Pages: Settings → Pages → Deploy from a branch → `main` / `(root)`. После этого сайт будет доступен по адресу `https://arrrtemka246.github.io/witch/`.

AQUA points используют официальную формулу World Aquatics `floor(1000 × (B / T)^3)` и базовые времена 2026. Для SCM используется таблица, действующая с 01.09.2026 по 31.08.2027; для LCM — с 01.01.2026 по 31.12.2026.
